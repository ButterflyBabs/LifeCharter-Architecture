## App Privacy ("nutrition labels")
Data linked to the user, used for App Functionality (not tracking):
- Contact info: name, email address, phone number (optional)
- User content: photos/videos, posts & messages, other user content (journal)
- Identifiers: user ID
- Usage data: product interaction (notifications read)
No data is used for tracking or advertising.
AI: when a member uses Mariposa (Collective Plus / Command Suite), the text involved is
sent to OpenAI after explicit in-app consent; not used for training.
